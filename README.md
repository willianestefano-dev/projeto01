# Sistema Escolar

## Descrição
Sistema de gerenciamento escolar desenvolvido em Python.
Projeto criado para demonstrar conhecimentos em Programação Orientada a Objetos (POO), manipulação de arquivos, CRUD, validações e estrutura de dados (listas, dicionários).
obs: Estou aprendendo ainda, mas chego lá.

## Funcionalidades

### 👨‍🏫 Professores
- Login com validação de senha
- Cadastro completo (nome, login, email, senha)
- Alterar dados (login, senha, nome, email)
- Remover professor
- Listar professores

### 👨‍🎓 Alunos
- Cadastro de alunos (nome, 3 notas)
- Cálculo automático de média
- Verificação de situação (Aprovado/Recuperação/Reprovado)
- Buscar aluno por nome
- Listar todos os alunos
- Ver alunos aprovados
- Ver alunos reprovados e em recuperação
- Remover aluno
- Alterar notas

### 📚 Livros
- Adicionar livros ao estoque
- Remover livros
- Verificar estoque disponível

### 👔 Funcionários
- Login de funcionários
- Cadastro (nome, senha, função)
- Listar funcionários
- Remover funcionários

## Tecnologias utilizadas
- Python 3
- Programação Orientada a Objetos (POO)
- Validações de dados (strip, isalpha, isdigit)
- Persistência em arquivos .txt

## Como executar

1. Clone o repositório
2. Execute o arquivo `projeto01.py`
3. Siga o menu interativo
